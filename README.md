# کی‌تموم؟ | Key Tamoom

برنامه فارسی راست‌چین برای تبدیل کارهای عقب‌افتاده به قدم‌های کوچک.

## ساختار پروژه
- `index.html`: داشبورد و مدیریت کارها
- `tasks.html`: میان‌بر مدیریت کارها
- `calendar.html`: کارها بر اساس سررسید
- `settings.html`: پوسته، پشتیبان‌گیری، بازیابی و حذف اطلاعات
- `css/styles.css`: استایل پایه
- `css/responsive.css`: استایل واکنش‌گرا و نوار ابزار موبایل
- `js/app.js`: مدیریت کارها، مراحل، فیلتر و اعلان مرورگر
- `js/calendar.js`: منطق صفحه تقویم
- `js/settings.js`: تنظیمات و پشتیبان‌گیری

## انتشار
بدون build یا نصب وابستگی. تمام فایل‌ها را با حفظ ساختار پوشه‌ها روی هاست قرار بده. برای GitHub Pages: Settings → Pages → Deploy from a branch → شاخه `main` و پوشه `/(root)`.

## محدودیت‌ها
داده‌ها در localStorage همین مرورگر ذخیره می‌شوند و بین دستگاه‌ها همگام نمی‌شوند. حساب کاربری واقعی، Backend و هوش مصنوعی متصل نیستند. اعلان در زمان بسته‌بودن سایت تضمین نمی‌شود.
