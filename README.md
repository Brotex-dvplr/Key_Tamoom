# کی‌تموم؟ | Key Tamoom

«کارهای عقب‌افتاده، دیگه نه!» — برنامه فارسی و راست‌چین برای مدیریت کارها.

## اجرا و انتشار
این نسخه استاتیک است و build یا نصب وابستگی لازم ندارد. در GitHub به Settings → Pages بروید، Deploy from a branch را انتخاب کنید و شاخه `main` و پوشه `/(root)` را منتشر کنید. صفحه اصلی `index.html` است.

## امکانات فعلی
- ایجاد، ویرایش، حذف و تکمیل کارها
- مهلت، اولویت، دسته‌بندی و وضعیت
- الگوهای مراحل قابل ویرایش برای مرجوعی سفارش، پرداخت قبض، تمدید مدارک، پیگیری پشتیبانی، تعمیر، ثبت‌نام و کارهای شخصی
- چک‌لیست مراحل و درصد پیشرفت
- محاسبه کارهای عقب‌افتاده، جست‌وجو و فیلتر
- حالت روشن/تاریک، خروجی پشتیبان JSON
- اعلان مرورگر با اجازه کاربر و هشدار موعد در زمان بازبودن صفحه
- کانال رسمی: https://ble.ir/key_tamoom

## ذخیره‌سازی و محدودیت‌ها
داده‌ها در localStorage همین مرورگر ذخیره می‌شوند و بین دستگاه‌ها همگام‌سازی نمی‌شوند. این نسخه حساب کاربری واقعی یا Backend ندارد؛ اطلاعات حساس وارد نکنید. اعلان‌ها در زمان بسته‌بودن سایت تضمین نمی‌شوند. هوش مصنوعی متصل نیست و الگوهای داخلی پیشنهاد مرحله می‌دهند. تقویم ماهانه مستقل و واردکردن فایل پشتیبان در این نسخه هنوز آماده نیستند.
